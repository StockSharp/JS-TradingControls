sstradingcontrols · StockSharp JS Trading Controls

Four browser trading panels — watchlist, positions, active orders, trade history — each rendering its own DOM and reaching the outside world through a single TradingHost object. This page runs the published dist/sstradingcontrols.js bundle over a demo host built in demo/demo.js: sample instruments, positions, orders and fills, no server and no network.
